# 安徽大学互联网学院历年资料库  
# Past Materials Archive of School of Internet, Anhui University

本仓库由安徽大学互联网学院学生自发整理与维护，主要收集各专业课程的历年试题、实验报告和复习资料，希望能给大家的课程学习和考试复习提供一些帮助。

资料会不定期更新，也欢迎大家一起补充和完善 (｀・ω・´)

**2026.06**  `智能科学与技术`正式搬至人工智能学院！原先资料将会保留。

- 历年试题：期中、期末及其他考试资料
