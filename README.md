本仓库由安徽大学互联网学院学生自发整理与维护，主要收集各专业课程的历年试题、实验报告和复习资料，希望能为大家的课程学习和考试复习提供一些帮助。

资料会不定期更新，也欢迎大家一起补充和完善 `(｀・ω・´)`

> This repository is voluntarily maintained by students of the School of Internet, Anhui University. It collects course materials for academic exchange and exam preparation.

## 资料内容 | Materials

- 历年试题：期中、期末及其他考试资料
- 实验报告：实验模板与参考资料
- 复习资料：课程重点、复习提纲等
- 其他与课程学习相关的资料

> Materials include past exam papers, lab report references, review outlines, and other course-related resources.
